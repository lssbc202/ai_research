### 多 Agent 编排学习中的高阶交互

> **原题**：[Learning Multi-Agent Orchestration:Higher-Order Interactions in Policy Improvement](https://arxiv.org/abs/2611.07495v1) \
> **作者**：Kaixuan Liu, Guojun Xiong \
> **机构**：Department of Computer Science, Emory University / John Hopcroft Center for Computer Science, Shanghai Jiao Tong University \
> **时间与版本**：v1 首次提交于 2026-11-05 13:58:30（北京时间），本次阅读 v1 [HTML](https://arxiv.org/html/2611.07495v1)。

**研究问题**

多 Agent 编排每次要决定由谁工作、给他哪些上游结果、何时结束。如果单独给每个动作评分，分析员可能因为拿不到证据而显得无用。把证据检索和分析一起改变，收益才显现。

**研究方法**

编排器可调用规划、证据检索、分析、校验、选择等固定角色，代码环境再加入测试修复。调用以类型化输入输出连接，编排器选择后继角色及可见的历史产物，最多 4 或 5 次决策。工作者都是冻结的 Qwen2.5-7B-Instruct。目标是任务准确率扣除调用 token 成本。 [§2 与实验设置](https://arxiv.org/html/2611.07495v1#S4.SS1)

IAPO 对每次动作更新施加概率比约束，从参考轨迹估计一阶效果和两次编排决策共同变化的效果。训练先拟合候选更新，再用独立验证轨迹给净回报改善计算下置信界。高阶余项由约束给出上界，下界为正才采用候选更新。 [§3](https://arxiv.org/html/2611.07495v1#S3)

**实际贡献**

论文把多步编排中的依赖转成可估计的训练项。以代码任务为例，测试修复需要先存在候选程序，一阶消融从未提议此组合，IAPO 的四个代码运行都采用了它。 [§4.4](https://arxiv.org/html/2611.07495v1#S4.SS4)

**结果与代价**

长输入 MBPP 的单回合成功率为 81.1%，DyLAN 为 71.2%，每题消耗约 5.1k 对 121.9k token。长输入 HumanEval 单回合为 83.7% 对 MaAS 的 83.8%，分别用 9.9k 与 26.5k token。在同检索器、角色和验证下加入交互项，相对一阶版本在这两项提高 17.3 和 7.2 个百分点。 [§4.2–4.3](https://arxiv.org/html/2611.07495v1#S4.SS2)

每轮要收集 6,400 条提案轨迹及 8,000 条验证轨迹，MBPP 单次训练搜索约耗 1.7 亿 token，独立于每题推理用量。长输入版本人为混入干扰单元，团队有 BM25 证据角色，公开系统基线没有相同检索器。系统间结果包含接口差异，同接口的一阶消融更适合判断交互项。 [§4.1](https://arxiv.org/html/2611.07495v1#S4.SS1)

**洞察评论**

编排训练可把输出是否交到正确的消费者作为可记录动作，而不只优化角色调用次数。验证下界针对固定分布的净回报，实际接入时仍需在目标任务分布上分别核算成功率、训练探索成本和线上推理成本。

### AttnSR：用策略注意力为交互步骤分配奖励

> **原题**：[AttnSR: Attention Step Reward for Long-Horizon Agentic RL](https://arxiv.org/abs/2611.07932v1) \
> **作者**：Mengsong Wu, Tianchen Zhou, Zhaochen Su, Zhenhua Liu, Zhe Cui, Aimin Zhou \
> **机构**：Shanghai Institute of AI for Education, East China Normal University / Shanghai Innovation Institute / Hithink Research / School of Data Science and Engineering, East China Normal University / The Hong Kong University of Science and Technology \
> **时间与版本**：v1 首次提交于 2026-11-05 20:37:19（北京时间），本次阅读 v1 [HTML](https://arxiv.org/html/2611.07932v1)。

**研究问题**

家庭任务或工具调用的正确性常在很晚才显现。训练器只在末步写入奖励时，同样的终局分数可能对应多条性质不同的行动序列。

**研究方法**

系统按 assistant 消息和观测划分步骤，在重算旧策略概率时捕捉部分层的 Q/K。把后续回复对前一轮回复及观测的注意力分别聚合，从末步沿步骤图向前回溯。近期偏差校正和跨层融合给出分配比例，历史注意力质量、集中度和层间一致性控制分配强度。 [§3.1–3.2](https://arxiv.org/html/2611.07932v1#S3.SS1)

每条轨迹以实际终局分数减滑动平均决定正负，再按比例写到各中间 assistant 步的末 token。原终局奖励保留，观测 token 只作上下文。新奖励进入 PPO 的优势和价值目标，更新 actor、critic 各自的 rank-64 LoRA，7B 基座冻结。 [§2、§3.3–3.4](https://arxiv.org/html/2611.07932v1#S3.SS3)

**实际贡献**

增量在于利用现有重放接口分配步骤反馈，不另训奖励模型，也不新增 rollout。注意力反映模型处理了什么，论文用置信门和最终结果给这个启发式加约束，奖励总量仍可能变化。 [§3](https://arxiv.org/html/2611.07932v1#S3)

**结果与代价**

Qwen2.5-7B-Instruct 的匹配 PPO 在 274 个 ALFWorld 留出任务上由 91.24% 升至 97.08%。线性位置奖励达到 92.34%，但该消融也移除了置信门。ScienceWorld 成功率 28.59%→30.90%，平均环境步数 30.68→21.51，成功率差在多重校正后不显著。WebShop 成功率 40.20%→41.00%，官方分数反降 1.03 点。 [§4.2–4.3](https://arxiv.org/html/2611.07932v1#S4.SS2)

主实验使用 8 张 H200、四个数据 epoch，逐任务配对区间以已训练策略为条件，无法估计训练种子间波动。注意力重建仍有二次量级的 Q/K 运算，未实测额外墙钟时间和峰值显存。 [§3.4 与训练设置](https://arxiv.org/html/2611.07932v1#S3.SS4)

**洞察评论**

可先把步骤边界、动作 token 和观测来源写进 rollout 记录，再比较仅终局、等预算位置奖励及注意力分配。若部署任务包含短回合或离散格式约束，应将成功率、部分完成得分和交互步数分开看。

### SKIM：针对结构化生成剪枝与蒸馏工具 Agent

> **原题**：[SKIM: Pruning Large Language Model Agents via Selective Knowledge Informed Masking](https://arxiv.org/abs/2611.07558v1) \
> **作者**：Moonseok Choi, Jongwon Jeong, Minki Kang, Giung Nam, Juho Lee \
> **机构**：KAIST / University of Wisconsin–Madison \
> **时间与版本**：v1 首次提交于 2026-11-05 15:04:45（北京时间），本次阅读 v1 [HTML](https://arxiv.org/html/2611.07558v1)。

**研究问题**

工具调用的 JSON 结构由运行时约束，模型真正要选的是函数与参数。标准剪枝校准和蒸馏把这些位置与可由语法确定的分隔符混在一起，分配给工具决策的容量因此可能不够。

**研究方法**

把序列分成上下文、决策和格式位置，对不同角色的激活加权以评估剪枝重要性，然后实际移除 MLP 通道和注意力组件。输出语法从既有前缀导出合法 token 集，其中仅有一个选项的格式位置无需学习如何选择。 [§4.1](https://arxiv.org/html/2611.07558v1#S4.SS1)

蒸馏前 25% 优化步骤以给定答案预热，后 75% 由学生在 XGrammar 中贪心生成，再把同一前缀交给冻结稠密教师。学生匹配合法词表上的前向 KL，并按 token 角色对齐隐藏层特征。改变的是剪枝后学生权重。 [§4.2、附录 B.2](https://arxiv.org/html/2611.07558v1#A2.SS2)

**实际贡献**

语法既决定推理动作空间，也决定学生训练时见到的前缀与损失支持集。论文还比较只重加权校准、移除蒸馏组件及混入常规蒸馏，展示受约束能力和自由生成之间的取舍。 [§5.6](https://arxiv.org/html/2611.07558v1#S5.SS6)

**结果与代价**

同蒸馏预算下，50% 名义稀疏度的 Qwen3.5-9B 在 BFCL-v3 结构化模式得 77.6%，SlimGPT 59.1%，原稠密模型 92.0%。SKIM 自由生成只有 1.3%，SlimGPT 为 62.5%。多步 HotpotQA 上，2B 同稀疏度 SKIM 的 F1 为 14.9，FLAP 为 13.3，稠密模型为 43.6。 [表 1 与 §5.4](https://arxiv.org/html/2611.07558v1#S5.T1)

训练用 4,096 条样本、2 epoch，双 A100 单次约 6–12 小时。论文在指定批量和序列长度下测得 9B 解码吞吐 1.41 倍、prefill 1.37 倍，未把模型速度当作多工具系统的端到端时延。 [§5.7、附录 B.2](https://arxiv.org/html/2611.07558v1#S5.SS7)

**洞察评论**

这种压缩适合可强制结构化的专用工具执行器。若同一模型还负责规划说明或与用户交谈，先测约束关闭时的质量，并分别记录工具参数正确率、多轮任务成功率和端到端延迟。

### 视觉 Token 路由：学习保留动作所需的图像区域

> **原题**：[Visual Token Routing: Learning to keep tokens that matter](https://arxiv.org/abs/2611.06854v1) \
> **作者**：Pranjal Aggarwal, Sean Welleck \
> **机构**：Carnegie Mellon University \
> **时间与版本**：v1 首次提交于 2026-11-05 02:10:33（北京时间），本次阅读 v1 [HTML](https://arxiv.org/html/2611.06854v1)。

**研究问题**

桌面 Agent 需要记住当前窗口中的细小控件，也会反复收到大面积未变化的截图。整图缩小会一起损失局部细节，按像素变化保留区域又可能丢失未变化但仍是下一步目标的控件。

**研究方法**

每十次观测留一张完整锚点，其余截图的各位置由 23.3M 参数的 MLP 读同位置近期历史，采样保留门。留下的 token 保持原坐标，按保留概率缩放以把动作监督传给路由器。部署在 vLLM 中继续使用同一门控。 [§2.2](https://arxiv.org/html/2611.06854v1#S2.SS2)

训练使用 CUA-World 桌面动作轨迹和游戏录像。对保留后的观测做动作交叉熵，联合更新 Qwen3.5-2B 的语言部分和路由器，视觉编码器冻结。另训练两条参照，分别看完整观测和仅锚点观测，用两者差距衡量完整历史的收益，再自适应调节保留 token 的惩罚。 [§2.3 与附录 A](https://arxiv.org/html/2611.06854v1#S2.SS3)

**实际贡献**

新增证据集中在把观测接口本身作为受训组件。冻结同一个初始路由器继续训模型，在 OSWorld 仅得 4.91，联合训练达 18.10，说明只调动作模型不足以恢复门控已经删掉的信息。 [§4.1](https://arxiv.org/html/2611.06854v1#S4.SS1)

**结果与代价**

OSWorld 每图平均视觉 token 从 2,040 降至 807.9，得分从 18.56 至 18.10，差 −0.46，95% 区间为 −2.88 至 +1.94。CUA-World 平均分从 16.61 至 16.34。按论文计价口径，OSWorld 推理成本约为稠密版的 1/2.4，单请求 prefill 约加速 2.3 倍。训练 2,000 步使用 8 张 H100，并行维护两种仅训练期参考策略。游戏结果衡量离线下一动作预测。 [附录 A、表 2–4](https://arxiv.org/html/2611.06854v1#A2)

**洞察评论**

训练可压缩界面观测时，保留一些完整参照让系统区分本来就难预测的动作和删掉证据后才难预测的动作。把任务成功率与视觉 token、prefill 和完整交互时延分开报告，能看出收益究竟出现在哪个环节。

### HITCH：经全身 Harness 教视觉语言模型操作人形机器人

> **原题**：[HITCH: Teaching a Vision-Language Model to Operate a Humanoid through a Whole-Body Harness](https://arxiv.org/abs/2611.08039v1) \
> **作者**：Qingzhou Lu, Chenxin Liu, Xinming Wang, Liu Cao, Yanjiang Guo, Mengdi Xu, Jianyu Chen \
> **机构**：Tsinghua University / Institute of Automation, Chinese Academy of Sciences / Shanghai Qizhi Institute \
> **时间与版本**：v1 首次提交于 2026-11-05 21:54:31（北京时间），本次阅读 v1 [HTML](https://arxiv.org/html/2611.08039v1)。

**研究问题**

人形机器人要把目标像素转换成可达的空间位置，还要完成身体各部位协调。教师若直接读取仿真真值，学生可能只能记住训练布局，无法从实际观测复现决策。

**研究方法**

测量工具让 VLM 在头部画面点选目标，由深度返回观测坐标系中的 3D 位置和标记图像。执行工具接受骨盆高度、躯干朝向、掌部路径、行走和视线等指令，由规划器生成全身参考，经 50 Hz 的 HEFT 跟踪器执行，再反馈实际身体状态。跟踪器还用教师执行过程中生成的参考继续训练。 [§III-A–C](https://arxiv.org/html/2611.08039v1#S3)

教师是仿真中的代码策略，只使用学生可见信息，例如以实际测量位置查询身体可达性表来决定姿势。五个基础任务各取 500 条成功示范，保留多轮工具回执。Qwen3.8-27B 对教师回复做交叉熵 SFT，更新语言模型全部权重、冻结视觉编码器。少样本版本比较只加新任务数据和与基础任务混合两种方案。 [§III-D–E](https://arxiv.org/html/2611.08039v1#S3.SS4)

**实际贡献**

把教师可见状态限定到部署接口，形成可解释的训练数据契约。论文独立更换低层跟踪器和关掉测距工具，因此能区分决策学习、可观测性和执行精度这三层。 [§IV-B–E](https://arxiv.org/html/2611.08039v1#S4.SS2)

**结果与代价**

同一 Harness 下，基础任务 SFT 把预训练 Qwen3.8-27B 的 SIMPLE 成功率由 3.3% 提至 51.1%，HumanoidArena 由 16.3% 提至 42.5%。SIMPLE 关闭测距后仅 2.8%。混入每任务 5 条示范达 95.0%，只训这 5 条则为 90.0%。真实 G1 搬箱 13/20、导航 6/10。两个仿真基准分别有 180、80 回合，指令和时间预算为适配此接口修改。 [表 II、§IV-A 与 IV-G](https://arxiv.org/html/2611.08039v1#S4.T2)

成功的真实搬箱回合平均 60.7 秒，约 61% 用于执行而约 19% 用于模型决策。论文披露示范量和实际运行时间，未给可横比的训练 GPU 小时。 [表 IV](https://arxiv.org/html/2611.08039v1#S4.T4)

**洞察评论**

工具接口要同时约束教师和学生能够看到什么。若终局失败既可能来自坐标测量，也可能来自执行跟踪，可以像论文一样固定命令替换执行器，再固定执行器替换策略，定位该补采哪类轨迹。

### PSGAgent：通过主动视觉工具学习生成全景场景图

> **原题**：[PSGAgent: Enhancing MLLMs' Dynamic Visual Perception for Panoptic Scene Graph Generation via Agentic Reasoning](https://arxiv.org/abs/2611.07408v1) \
> **作者**：Qingyun Liu, Yuankun Liu, Jiaye Feng, Jie Huang, Zonghong Dai, Haochen Li, Jingkun Wang, Weiping Li, Tong Mo \
> **机构**：Peking University / AlignBase \
> **时间与版本**：v1 首次提交于 2026-11-05 12:02:16（北京时间），本次阅读 v1 [HTML](https://arxiv.org/html/2611.07408v1)。

**研究问题**

全景场景图把图像表示为物体掩膜与物体间关系。小目标可能在整图中难看清，而“拿着”和“靠着”等关系也可能被背景干扰。模型需要学会何时换一张更适合判断的观测。

**研究方法**

Harness 提供按边框放大的工具，以及只显示主体与客体掩膜并集的高亮工具。先训练常规场景图模型并收集错判，再按小目标、边缘位置或关系混淆筛样，合成带工具调用和返回图像的多轮示范，供 Qwen2.5-VL-3B 冷启动 SFT。 [§3.1–3.2](https://arxiv.org/html/2611.07408v1#S3.SS1)

GSPO 每题采三条轨迹，更新模型的整段行为。最终关系与实体位置共同验收，奖励还考虑有效 JSON、缩放区域是否覆盖正确预测的关系、边缘探索和重复裁剪。高亮侧也按关系正确性和难度给奖励。高亮掩膜来自预训练 Mask2Former。 [§3.3、§4.1](https://arxiv.org/html/2611.07408v1#S3.SS3)

**实际贡献**

论文展示了如何让感知工具的回执同时成为 SFT 上下文和 RL 的验收依据。所谓裁剪因果奖励使用裁剪与最终正确关系的几何对应，未比较同一状态关闭该次调用后的反事实结果。 [§3.3.3](https://arxiv.org/html/2611.07408v1#S3.SS3.SSS3)

**结果与代价**

在 PSG 的场景图检测任务中，完整 GSPO 的 Recall@100 为 50.27，mRecall 为 42.88，无工具 GSPO 为 39.31 和 27.71。相同工具组合的 GRPO 行为对应 47.92 和 41.79。去掉两类工具奖励后 Recall/mRecall 降至 43.63/35.72。SFT 约 8K 示范、5 epoch，GSPO 在四张 A6000 上约七天，推理最多五轮。掩膜漏检会使结果退化，论文未给独立迁移场景的总交互成本。 [表 5–8、训练设置](https://arxiv.org/html/2611.07408v1#S4.SS3)

**洞察评论**

主动视觉 RL 可以奖励调用后得到的可验收证据，避免只奖励发生了调用。若定位工具用独立分割器，应把它的漏检、坐标误差和决策策略错误分别记录，防止把观测噪声误当成策略探索问题。

### 多违规知识图谱修复的选择性检索路由

> **原题**：[Selective Retrieval Routing for Multi-Violation Knowledge Graph Repair](https://arxiv.org/abs/2611.07342v1) \
> **作者**：Tung-Wei Lin, Gabe Fierro, Han Li, Tianzhen Hong, Pierluigi Nuzzo, Alberto Sangiovanni-Vinentelli \
> **机构**：UC Berkeley / Colorado School of Mines / Lawrence Berkeley National Laboratory \
> **时间与版本**：v1 首次提交于 2026-11-05 10:29:58（北京时间），本次阅读 v1 [HTML](https://arxiv.org/html/2611.07342v1)。

**研究问题**

知识图谱修复器可以在结构合法的多个答案间选择，但外部文档只对部分违规提供正确证据。检索也增加上下文和研究 Agent 的开销，给所有违规都开放工具未必划算。

**研究方法**

从合法参考图注入兼容的多种违规，记录能还原原图的编辑。执行时先校验并聚类违规，再由路由器选择开放研究 Agent 的修复提示或关闭版本。每个训练案例各运行一次常开和常关，以实际修复簇的谓词多热向量作输入，以相对参考编辑的 F1 作监督。 [§6–7](https://arxiv.org/html/2611.07342v1#S7)

分别用两条轨迹拟合两个 XGBoost 回归器。推理只在预计 ON 分数更高时开放工具。LLM 工作模型固定，受训的是执行框架的访问控制组件。两种运行可产生不同的修复簇，因此预测差依赖各自轨迹分布。 [§7](https://arxiv.org/html/2611.07342v1#S7)

**实际贡献**

贡献是把是否开放检索写成可监督的执行决定，并用可逆违规制造训练标签。同为 223P 图谱，某些谓词的检索收益在两个部署之间方向相反，支持按部署收集配对实验。 [§5 与 §9](https://arxiv.org/html/2611.07342v1#S9)

**结果与代价**

两套楼宇图谱、每套三种违规混合、每组 80 例。路由器在六组均比常开省 token，五组比常关 F1 高。IBAL 证据组仅开放 53% 的簇，论文未检出相对常开的 F1 差异。IBAL 表征组相对常开有 61 胜、12 负、7 平，但仍比常关更差也更贵。在线用量比较不含两套训练轨迹的执行开销，路由决策也尚未把 token 成本显式纳入。 [§8、表 1](https://arxiv.org/html/2611.07342v1#S8)

**洞察评论**

这类对照能为低成本工具门控积累训练样本，前提是有可信的参考结果。迁移时可同时测相对常关、常开和等开放比例随机路由的表现。使用阈值前应检查新增调用成本和预测误差，因为极小的分数差也会触发检索。

### BiGrounder：双向训练图形界面定位执行器

> **原题**：[BiGrounder: Bidirectional Training Unlocks the Potential of GUI Grounding](https://arxiv.org/abs/2611.07765v1) \
> **作者**：Dengyao Shi, Tianyu Fu, Fei Hu, Anyang Su, Hanning Wang, Shuo Wang, Minghui Wu, Chenxu Zhao, Zhen Lei \
> **机构**：MAIS, Institute of Automation, Chinese Academy of Sciences / Mininglamp Technology / School of Advanced Interdisciplinary Sciences, University of Chinese Academy of Sciences \
> **时间与版本**：v1 首次提交于 2026-11-05 18:05:14（北京时间），本次阅读 v1 [HTML](https://arxiv.org/html/2611.07765v1) / [LaTeX 源文件](https://arxiv.org/src/2611.07765v1)。

**研究问题**

同一个按钮可被不同措辞指代。执行器只模仿固定文字到坐标的映射时，规划器换一种说法就可能点错。单用文本相似度又不能分清长得相似的按钮。

**研究方法**

双向 SFT 同时训练指令到动作坐标、坐标到自然语言描述。由 SFT 模型先筛出语义相符但并非总能正确定位的样本，构成约 63k 条 RL 数据。 [训练样本筛选](https://arxiv.org/html/2611.07765v1#Sx3.SSx3)

RL 时用当前模型从同一坐标生成四条措辞，每条再做四次前向定位。反向语义奖励须通过阈值且至少有一次定位回目标，前向按动作与位置验收。GRPO 同时更新反向生成和前向定位所共享的模型，部署时只把定位模型接到规划器后。 [训练方法与评测](https://arxiv.org/html/2611.07765v1#Sx4.SSx3)

**实际贡献**

新增机制是让训练接口回放自己产生的指令，并用定位结果验收改写。它允许在目标坐标一致的前提下更新措辞分布，比只给已有文本做静态增广多了一层执行核验。 [§方法与附录 E](https://arxiv.org/html/2611.07765v1#A5)

**结果与代价**

Qwen3-VL-4B 的五项静态定位平均分为 65.2，双向 SFT 为 67.6，RL 无循环门控为 70.1，加门后为 72.8。同一 GPT-4o 规划器下，AndroidWorld 从 68.9% 升到 72.4%，OSWorld 从 40.2% 升到 42.8%，后者限 50 步。4.482M SFT 样本训练两轮，RL 一轮每样本 20 条正反向生成。静态定位涨幅超过整任务涨幅，论文未给可比的 GPU 小时。 [表 1、2、5](https://arxiv.org/html/2611.07765v1#Sx4)

**洞察评论**

把自生成指令接回真实执行器是筛掉表面语义相似、行为却不一致样本的一种方式。真实应用应额外测试多种规划器和相似控件密集的界面，定位循环正确仍可能绕开更长任务中的规划错误。

### Micius-Flash：面向工程的轻量 Agent 模型

> **原题**：[Micius-Flash: Lightweight Agentic Intelligence for Engineering](https://arxiv.org/abs/2611.10015v1) \
> **作者**：Hongcheng Gao, Weiheng Li, Yipeng Wei, Yu Lei, Shuo Sun, Yi Li, Yajiao Wang, Jie Luo, Jianwei Wen, Xinyi Zhou, Hongda Li, Yibing Zhang, Henghui Sun, Yufan Zhou, Tianfang Hao, Naihao Xue, Hailong Qu, Jingjing Zhou, Peng Xu, Yongzheng Wei, Yichen Zhu, Ziying Wang, Yibo Wang, Jianshu Zeng, Yuhang Lei, Zeqiang Wang \
> **机构**：未核实，原文署名 Micius Team \
> **时间与版本**：v1 首次提交于 2026-11-05 01:53:55（北京时间），本次阅读 v1 [HTML](https://arxiv.org/html/2611.10015v1)。

**研究问题**

半导体设计既需要知道领域知识，也要能操作 EDA 工具和工程文件。真实场景少且昂贵，单独训练的领域专家又难以直接作为一个通用执行策略部署。

**研究方法**

以 500 多个经专家审查的工程场景为种子，把资料落到数据库和文件工作区，包装专业软件及库接口。任务用有向无环图定义操作依赖，只给执行 Agent 任务目标及部分条件，要求它通过工具取回缺失信息。编译、仿真和沙箱执行用于筛选编码与工具轨迹。 [§2.2–2.4](https://arxiv.org/html/2611.10015v1#S2.SS4)

先以 SFT 训练知识推理、编码、多模态、Agent 四位专家并预热学生，再用当前学生的响应或交互轨迹，按任务类别选一位教师。教师保留 top-32 概率和聚合尾部概率，学生在实际走过的上下文做前向 KL。部署工程台另报告阶段化的 Capability Broker、工程产物查看器和本地／远程执行接口。 [§3、§5](https://arxiv.org/html/2611.10015v1#S3)

**实际贡献**

工程任务生成和执行核验有明确的教师与学生训练消费者。部署时的 EDA 案例进一步展示可用的工具接口，论文没有逐一验证每个部署子系统对训练分数的贡献。 [§5–6](https://arxiv.org/html/2611.10015v1#S5)

**结果与代价**

在自建 Semiconductor Agent 中，Micius-Flash 得 62.41%，同尺寸 Qwen3.8-27B 为 45.22%，差 17.19 点。PCB Agent 为 83.30% 对 60.00%，工程案例有工具反馈和多步产物检查。原文没披露可独立核算的 Agent 轨迹量或整体训练 GPU 时，也未做等数据、等算力的教师路由与 Harness 分解，数字体现整套配方。 [表 1、§6](https://arxiv.org/html/2611.10015v1#S4.T1)

**洞察评论**

领域 Agent 的可执行任务可同时约束工具、工作区和验收规则，并记录每类轨迹由哪位专家监督。做复验时宜固定同一工具集，比较静态示范、学生在线采样与去除单个专家的效果。

## 领域结构与研究进展

### 1. 观测与动作接口

Agent 的训练信号取决于它看到什么、能做什么，以及系统知道哪一步执行成功。VTR 保存工具回执并标记动作边界，便于在收集轨迹后做监督训练。HITCH 把意图决策和低层动作交给不同组件，用可执行的测试环境生成规划器训练信号。两者分别改变了可用证据与可选动作。固定任务与模型后，可分别检查同一回执给谁看、哪一级动作有监督，避免把两者的收益混在一起。 [VTR](https://arxiv.org/html/2611.06854v1) · [HITCH](https://arxiv.org/html/2611.08039v1)

PSGAgent 的页面关系图让视线目标带有空间邻接信息，BiGrounder 则把输出坐标交给双向一致性检查。这类中间状态可以进入奖励或策略优化，前提是检查结果与真实动作成功相符。定位准确率适合衡量屏幕上的一个步骤，完整任务还依赖目标状态是否持久和动作能否正确串联。 [PSGAgent](https://arxiv.org/html/2611.07408v1) · [BiGrounder](https://arxiv.org/html/2611.07765v1)

### 2. 奖励与信用分配

终局成败出现后，Harness 可以决定训练器能把反馈写回哪里。AttnSR 用轨迹重放，把注意力和最终奖励折回已有动作，新增的是步级训练标签。IAPO 在同一 Harness 下改变多项编排决策，用独立轨迹估计组合更新，新增的是对动作互补性的检验。前者的额外计算随序列变长，后者需要大量验证轨迹。两篇均有对照，能回答的分别是步级代理奖励是否有用和二阶决策依赖是否值得显式拟合。 [AttnSR §3–4](https://arxiv.org/html/2611.07932v1#S3) · [IAPO §3–4](https://arxiv.org/html/2611.07495v1#S3)

Selective Retrieval Routing 把反馈压到一个二选一决策。固定后续回答模型，分别跑检索和直接回答，就能给同一题取得两路训练信号。这种做法适合少量可复跑的分支，IAPO 处理的是组合数随决策次数增加的情形。设计新 Harness 时，可以先判断哪些分支值得保留成对结果，再确定哪些地方需要学多步策略。 [Selective Retrieval Routing](https://arxiv.org/html/2611.07342v1) · [IAPO §3](https://arxiv.org/html/2611.07495v1#S3)

### 3. 部署约束与策略蒸馏

SKIM 把部署时允许的 token 集同时用于校准和蒸馏，因此能保住受约束工具调用的能力，释放相同模型做自由生成时却会明显退化。Micius-Flash 把工程环境中学生实际走过的前缀交给不同教师，监督内容随工作区、工具接口和验收规则变化。前者有较直接的同预算对照，后者给出整套系统的结果，教师路由与训练环境的独立增量仍缺少拆分。两篇合起来指出了应在实验记录中注明的两个变量，即部署约束实际是什么，以及教师在哪些前缀上提供监督。 [SKIM §4–5](https://arxiv.org/html/2611.07558v1#S4) · [Micius-Flash §2–3](https://arxiv.org/html/2611.10015v1#S3)

## 总结与启示

- **先固定可重放的轨迹接口。** 记录模型可见状态、角色或工具调用、合法动作约束、执行回执、发生错误的位置和终局验证。后续做 SFT 或 RL 时才能区分模型选错动作、工具失败和评估器误判。
- **从可控的干预开始。** 对检索、校验等少量分支，可让同一输入走两遍，比较真实收益。对长序列的步级奖励，保留终局奖励和等预算启发式对照，并分任务报告退化。
- **用两套成本账检验收益。** 汇报训练轨迹、验证轨迹和评估调用，也单列部署每题用量、成功率与耗时。系统级提升和组件消融分别记录，以便判断下一轮该改数据、奖励还是执行接口。
