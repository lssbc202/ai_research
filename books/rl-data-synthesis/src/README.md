# RL 数据合成与 Harness 优化：论文调研与分析

本书汇集与强化学习数据合成、Agent Harness 优化有关的论文阅读日报、方法研究与横向比较，随着调研工作持续更新。

阅读日报以 Markdown 为原始记录，按研究主题归入章节目录。所有文章既可以在线逐篇阅读，也可以下载合并后的整本 HTML，便于连续阅读、检索和综合分析。

## 阅读方式

- 左侧目录按研究主题组织内容。
- 页面内搜索可用于检索在线书籍。
- [整本书 HTML](complete.html) 将全部内容汇总到一个文件，便于离线保存与分享。

本书处于持续建设阶段，初始章节仅用于明确内容范围，不代表已经完成相应论文的调研。
