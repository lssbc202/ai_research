# Agent harness与后训练

本书收录 Agent Harness、强化学习数据合成和大模型后训练相关论文的调研与分析日报，按月份归档，并持续更新。

## 目录规则

每年按月份建立一级目录，例如 `2026-10`、`2026-11`；每月内按日期建立 Markdown 日报，例如 `2026-10-16.md`。每篇日报正文中的一级标题将作为书籍导航里的文章标题。

你可以从左侧按月份浏览每日内容，使用在线全文搜索，也可以通过书籍首页提供的 `complete.html` 地址获取全书单 HTML，方便离线阅读、检索和分享。
